# アクアのGrok空♡天気

Grokと一緒に作った、シンプルで可愛い天気アプリです。

現在の天気・1時間ごと予報・週間予報を表示し、  
天気に合わせて「今日のGrokへのひとこと」を提案してくれます。

## スクリーンショット

![スクリーンショット](https://github.com/aqua-grok/aqua-grok-weather/blob/main/screenshot.png)

## 主な機能

- 現在の天気表示（気温・風速）
- 1時間ごとの予報
- 週間予報
- 天気に応じた「今日のGrokへのひとこと」
- 都市の切り替え（東京・大阪・札幌など多数）
- 更新ボタン

## 技術スタック

- Python 3.x
- tkinter
- requests
- Pillow
- Open-Meteo API（無料）
